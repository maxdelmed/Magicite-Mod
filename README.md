# Memoria Magicite

A custom Minecraft Forge 1.20.1 mod made for a fan dedicated server, inspired by the magic system in Final Fantasy Crystal Chronicles.

Magicite can be found while exploring and is used to cast spells like Fire, Blizzard, Thunder, Cure, Clear, and Life. Spells can also be combined with other players to create stronger effects/larger range.
There is also a built-in way to solo cast the stronger versions of spells, but a lot of the charm in this mod comes from cooperation.

The mod also includes interactions with most vanilla blocks, for example Blizzard creates ice on water surfaces, Fire cooks food and lights campfires, Thunder can interact with redstone through a lightning rod, etc.

## Development

This is the first upload to GitHub, but the mod has been in development for a while. I'm starting the repository with the latest version rather than uploading all the older builds since theyre all for the same version of Minecraft (1.20.1).

I'm still working on it and will be updating the repository as I make changes and test their correct functionality.

## Building

Requires Java 17. Run `BUILD_MAGICITE.bat` on Windows or follow `BUILD_ON_WINDOWS.md`. The helper downloads the Forge development kit and builds the source. Use the resulting JAR from `READY_FOR_TEST/` after a successful build.

The optional `kubejs_optional` folder contains loot configuration for KubeJS/LootJS. It is not installed automatically and you may ignore it if you want to keep the magicite off loot tables.

I'll add an easy install when I feel content with the mod.
